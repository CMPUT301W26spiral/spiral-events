      • Notification

        Notification(String title, String message, String type, String recipientId, String eventName, String eventId)

        Constructs a new Notification with the specified details.

        Parameters:
        title - The title of the notification (e.g., "Accepted", "Denied").
        message - The descriptive message of the notification.
        type - The type of notification determining UI styling (e.g., "ACCEPTED").
        recipientId - The device ID of the user receiving the notification.
        eventName - The name of the event associated with this notification.
        eventId - The unique ID of the event for navigation purposes.
